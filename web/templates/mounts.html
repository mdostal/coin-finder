Mount keeps disconnecting? Attach a dedicated Google API client to "{{ r.name }}"

By default every remote signs in through rclone's own shared Google API client -- its request quota is shared across every rclone user on earth, not just you. Under sustained scanning that shared quota can run out (Google replies with a rate-limit error), which looks like the mount randomly dying every 20-30 minutes. Giving "{{ r.name }}" its own dedicated client (free, from your own Google account) gives it its own private quota and fixes this for good.

Getting a Client ID and Client Secret from Google Cloud Console (first time only -- five minutes, all done in your browser):

  1. Go to Google Cloud Console and sign in with the same Google account this Drive belongs to. Click the project dropdown at the top and choose New Project (any name, e.g. "coin-finder") -- or reuse an existing project if you already have one.
  2. Enable the Drive API: with that project selected, use the search bar at the top and search for Google Drive API, open it, then click Enable.
  3. Configure the consent screen: in the left sidebar go to APIs & Services → OAuth consent screen. Choose External (unless you have a Google Workspace account), fill in an app name (anything) and your own email as the support and contact email, then save. You can leave scopes and test users on their defaults -- you don't need to publish it.
  4. Create the client: go to APIs & Services → Credentials, click + Create Credentials → OAuth client ID, and set Application type to Desktop app. Give it any name and click Create.
  5. Copy the two values shown -- Client ID and Client secret -- straight from that confirmation screen (or later from the client's own detail page under Credentials). Paste the two plain values into the fields below. Do not upload or paste the contents of a downloaded client_secret_....json file -- this form needs just the two bare strings shown on the page, not the JSON file.

Submitting opens your browser to re-sign in to Google with the new client and approve access again -- the same "Allow" screen as before. "{{ r.name }}" keeps its name and everything already bound to it; only its Google API client changes. Your client secret is stored in the vault (Portunus), never in this app's own plaintext state.
