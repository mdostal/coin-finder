Scan Google Drive

Slow-crawls your Google Drive for wallet-like files and downloads matches directly to a local directory -- the same tools/scan_google_drive.py tool and OAuth flow documented in the README, just started from here. First use requires the one-time Google Cloud OAuth setup described there (a credentials.json in this project's root); the first run will open a browser window for consent.

Multi-terabyte Drive that can't be downloaded locally? See mounting Google Drive with rclone instead -- once mounted, point the regular scan form at the mount point like any local directory.
