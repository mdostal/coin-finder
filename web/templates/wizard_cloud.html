Clicking Connect opens your browser to sign in to Google and approve access -- the same "Allow" screen you'd see for any app asking to use your account. It opens in your regular browser, not inside this window. rclone only ever reads your files (this project mounts everything read-only), never writes or deletes anything. This is all most people need -- the fields below are for a specific, rare situation, not a required step.

Advanced: use your own Google API credentials (optional, most people should skip this)

Leave both blank -- the button above already uses rclone's own shared credentials and works without anything here. Only fill this in if Google has specifically throttled the shared credentials for you (rare, only happens with very heavy scanning), and only with a REAL client ID/secret from Google Cloud Console via rclone's guide -- a real client ID always ends in ".apps.googleusercontent.com". Typing anything else here (a password, a made-up name) will fail with a confusing Google error page instead of working -- if in doubt, leave this blank. Your client secret is stored in the vault (Portunus), never in this app's own plaintext state.
