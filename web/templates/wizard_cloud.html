Attach {{ "Google Drive" if kind == "gdrive" else "a GCS bucket" }}

Multi-terabyte cloud storage can't be scanned by downloading it all first -- there isn't enough disk space or time for that. Instead, this attaches it as a folder your Mac can browse directly, fetching each file's contents only when something actually needs to read it.

Step 3 -- Mount it

Once you've done steps 1 and 2, head to the Mounts page to actually attach it and check it's working -- that page shows a real, live status (not just "it didn't error"), and lets you add it to your saved scan targets once it's confirmed healthy.
