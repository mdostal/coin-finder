Search Gmail for wallet clues

Searches Gmail for old exchange signup/withdrawal emails, wallet mentions, and wallet-like attachments (wallet.dat, backups, etc.) -- the same tools/scan_gmail.py tool, just started from here. Every email's body/attachment content flows straight from Google's API to local disk; only public info (sender, subject, date, any bitcoin-style address found) ever gets shown back to you here or to any AI assistant helping with this project.

Connect Gmail

One-time setup, in your own Google account:

  1. Go to the Google Cloud Console, create a project (or use an existing one -- the same one used for Google Drive works fine).
  2. Enable the Gmail API for that project.
  3. Create an OAuth client ID credential of type Desktop app.
  4. Paste its client ID and client secret below.

Both are stored in your vault (Portunus), never as a plaintext file -- the same place every saved password in this app lives. The next step opens a real browser window for you to approve read-only Gmail access; nothing is searched until you do.
